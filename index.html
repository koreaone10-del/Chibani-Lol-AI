📚 الدليل المرجعي الكامل لأوامر وخصائص Google ARTEMIS

        

          

            
              

                المكون / الأمر
                الكود / الصيغة
                الشرح التقني
              

            
            
              

                التشغيل الفوري
                ./start.sh أو .\start.bat
                يثبت Python uv و ADB و scrcpy و FFmpeg ويبني واجهة الويب على المنفذ 8000.
              

              

                تشغيل نمط Flash
                uv run artemis run "Task" --profile flash
                حلقة سريعة (3-5 ثوانٍ للخطوة) بدون LangGraph للمهام المباشرة.
              

              

                تشغيل نمط Pro الصارم
                uv run artemis run "Task" --profile pro --verification-level strict
                تخطيط متعدد الفروع مع تحقق قبل كل نقرة ومراجعة شاملة عبر Checker.
              

              

                إدارة المساعد (Helper)
                uv run artemis helper install | status | uninstall
                التحكم بتطبيق Accessibility Helper المسؤول عن قراءة شجرة الواجهة بسرعة.
              

              

                التشغيل عن بُعد (SSH)
                ssh -L 8000:localhost:8000 user@host
                تمرير منفذ واجهة الويب للتحكم بهاتف متصل بخادم سحابي أو جهاز بعيد.
