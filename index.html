🛠️ الحل الجذري لفشل بناء `U-Boot 2019.01` (`error: unknown type name 'ulong'` في `tools/atmelimage.o`)

انسخ هذا السكريبت ونفذه في الطرفية (أو ضعه في GitHub Actions) لإصلاح خطأ `ulong` في `tools/atmelimage.o` وخطأ `yylloc` وإنتاج ملف `u-boot-sunxi-with-spl.bin` لبوردة R69-EMCP v2.0 بتردد 336MHz: 

# 1. حل خطأ: error: unknown type name 'ulong' في tools/atmelimage.o
sed -i '1i #include \n#ifndef ulong\ntypedef unsigned long ulong;\n#endif' include/compiler.h

# 2. تهيئة الإعدادات لبوردة Allwinner H3 وضبط تردد رام R69 على 336MHz
make ARCH=arm CROSS_COMPILE=arm-linux-gnueabihf- orangepi_one_defconfig
sed -i 's/CONFIG_DRAM_CLK=.*/CONFIG_DRAM_CLK=336/' .config
sed -i 's/CONFIG_DRAM_ZQ=.*/CONFIG_DRAM_ZQ=3750393/' .config

# 3. بناء u-boot-sunxi-with-spl.bin مع تمرير إعدادات المترجم HOSTCFLAGS الصحيحة
make -j$(nproc) \
  ARCH=arm \
  CROSS_COMPILE=arm-linux-gnueabihf- \
  HOSTCFLAGS="-O2 -D_GNU_SOURCE -Dulong='unsigned long' -include sys/types.h -fcommon -Wno-deprecated-declarations" \
  HOSTLDFLAGS="-fcommon"
